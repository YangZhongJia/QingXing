# 桌面健康提醒 V1.0 · 测试报告

> 执行环境：Windows 10/11（本机双屏 DELL P2424HT 1920×1080 主屏 + DELL P2425H 1920×1080 副屏，任务栏位于主屏底部 40px，两屏 DPR=1.0）；
> 运行 Python 3.14.7（`C:\Program Files\Python314\python.exe`，与 PRD 的 3.12 存在已声明偏差）；
> PySide6 6.11.2 / Qt 6.11.2；pytest 9.1.1 + pytest-qt 4.5.0。
> 所有结论均来自真实执行的命令、自动化测试或真机截图/日志，不写「预期通过」。

## 1. 测试方法

| 层 | 手段 | 说明 |
| --- | --- | --- |
| 核心逻辑 | pytest + 可注入 `FakeClock` | 不经过 Qt，直接驱动 Scheduler/Storage，覆盖计时、队列、暂停、时钟跳跃、损坏配置 |
| 浮窗/UI | pytest-qt（`QT_QPA_PLATFORM=offscreen`） | 断言窗口 flags、位置计算、键盘事件被忽略、卡片交互 |
| 系统集成 | pytest + 隔离注册表键 | 单实例（真实 QLocalServer/Socket）、HKCU Run、托盘菜单结构 |
| 真机 E2E | 真实 windows 平台 + 逐屏截图 + 应用日志 | 证明浮窗真的浮在其它程序之上、右下角不压任务栏、点击确认链路可用 |
| 打包 | PyInstaller onedir | 无 Python 环境机器上启动验证 |

执行命令：

```powershell
python -m pytest                    # 全量
python -m pytest -q -k scheduler    # 某一组
python app.py --config .e2e\custom\config.json --exit-after 30   # 真机 E2E
python scripts\e2e_screens.py --out docs\screenshots             # 真机截图
```

**全量结果：134 passed in 2.25s**（每次改动后重跑，无跳过、无 xfail、无空壳用例）。

### 3.1 独立复核发现并已修复的缺陷

| 缺陷（独立 QA 复核） | 根因 | 修复与回归 |
| --- | --- | --- |
| 删除正在弹窗的自定义提醒后，浮窗永久残留、后续提醒全部堵塞，点「我知道了」报错 | `ReminderManager.on_state_changed` 用 `Scheduler.task()` 取已删除任务，抛 `KeyError` 被槽吞掉 | 改用 `config.get_task()` 判空 → `_dismiss()+sync()`；回归 `test_removing_shown_task_dismisses_popup` |
| 暂停中新增提醒会立刻到期（暂停未冻结新任务） | `add_task` 固定 `ACTIVE + next_due` | 暂停时新任务置 `PAUSED + remaining=interval`；回归 `test_add_task_while_paused_starts_frozen` |
| 未保存的间隔编辑在关闭时静默丢弃 | 无未保存处理 | `closeEvent` 前 `commit_edit()` 自动保存，非法值红字提示且不落盘；回归 2 条 |
| 自定义提醒图标缺失导致 `qt.svg` 告警 | 无 `assets/custom.svg` | 新增资源 `assets/custom.svg`（已打进 EXE） |

## 6. 已知限制与未覆盖项（如实声明）

1. **DPI 125%/150% 未真机目测**：本机双屏缩放均为 100%。已用合成可用区 + `QT_SCALE_FACTOR` 验证位置与尺寸公式，但真机高缩放下「控件不截断」仍需人工确认（TC-024 记为部分通过）。
2. **任务栏在侧边/顶部未真机验证**：真机任务栏在底部；算法层用合成 `QScreen.availableGeometry()` 验证（TC-025 部分通过）。
3. **10 分钟静置未人工等待**：无自动关闭代码 + 键盘/关闭事件被拦截已由单测证明；真机观察到点击前浮窗保持显示（TC-009 记为机制级通过）。
4. **休眠/锁屏未真机等待**：用 `FakeClock` 模拟休眠超过两个截止时刻，验证「每任务最多一条」（TC-021）。
5. **安全桌面/独占全屏**：Windows UAC 与独占全屏游戏的置顶可见性不在可控范围，PRD 已声明为边界（程序不负责）。
6. **托盘图标外观**：本机可创建托盘图标（`test_tray_available_and_start_return_bool` 通过），但图标在通知区折叠面板中的实际外观与点击行为未人工截图。
7. **主窗 X 关闭到托盘**：单测覆盖（`closeEvent` ignore + `hidden_to_tray`），真机未用鼠标点 X。
