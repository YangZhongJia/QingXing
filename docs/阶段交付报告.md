## 阶段一：核心逻辑（调度 / 持久化 / 时钟）

### 1. 目标

- 唯一全局 `Scheduler`，可注入 `Clock`，任务卡片与 UI 不持有业务定时器。
- 计时用「持久化到期时间」判断，不靠 tick 累加；先落盘、后通知 UI。
- 同时到期按 (到期时刻, 任务ID) 排队；同一任务最多一条待确认；逾期不堆积。
- 间隔 1~720 整数分钟，配置原子写、损坏备份并回落默认。

### 2. 文件清单

| 文件 | 说明 |
| --- | --- |
| `src/models.py` | Task/PendingEntry/AppConfig/Reminder、`validate_interval`、UTC ISO 序列化、`repair()` 自愈 |
| `src/clock.py` | `Clock` 协议 / `SystemClock` / `FakeClock` |
| `src/scheduler.py` | tick/acknowledge/pause/resume/set_interval/set_enabled/add_task/remove_task、时间跳跃保护 |
| `src/storage.py` | `%APPDATA%\DesktopHealthReminder\config.json`，tmp+fsync+`os.replace`，损坏备份 `config.corrupt-*.json` |
| `src/logger.py` | 轮转日志 1MB×5、excepthook |
| `tests/conftest.py`、`tests/test_scheduler.py`、`tests/test_settings.py` | FakeClock + 持久化顺序断言 |

### 3. 功能与取舍

- 到期判定 = `next_due_at <= now`，tick 只做一次扫描；休眠唤醒不会产生 N 条重复（每任务队列去重）。
- 确认后以「确认时刻 + 间隔」重排（TC-008 语义），暂停期间确认的任务在恢复后给完整间隔。
- 时间回拨 >300s 把 next_due 夹到 now+interval；前跳 >1h 记 warning，避免修改系统时间导致通知风暴。
- 取舍：`repair()` 采用「尽量自愈而非报错」——坏配置不阻止启动，但记录 warning 并备份原件。

### 4. 真实命令与结果

```
python -m pip install pytest pytest-qt        → pytest 9.1.1 / pytest-qt 4.5.0
python -m pytest                              → 52 passed
```

### 5. 已知问题

- 无 UI，所有交互尚不可见（阶段二解决）。
- Python 3.14.7（PRD 写 3.12）——已声明偏差，PySide6 6.11.2 在 3.14 下工作正常。

## 阶段二：主窗与强提醒浮窗

### 1. 目标

- 主窗 780×600：两条任务卡片、间隔输入/chips/开关/测试按钮、暂停、设置面板、底部测试按钮。
- 强提醒浮窗：`Tool|Frameless|StaysOnTop`，360×150~190，右下 16px，不遮任务栏，不抢焦点；只能点「我知道了」关闭。
- 队列：一次一张，确认后弹下一条；测试提醒不写盘、不影响正式倒计时。

### 2. 文件清单

| 文件 | 说明 |
| --- | --- |
| `src/ui/main_window.py` | 主窗、`SettingsPanel`、`AddReminderDialog`、卡片滚动区、toast |
| `src/ui/task_card.py` | 单任务卡（徽章/倒计时/间隔/chips/开关/测试/删除） |
| `src/ui/reminder_popup.py` | 强提醒浮窗、自绘阴影、`compute_position`、关闭拦截 |
| `src/ui/style.qss`、`src/ui/__init__.py` | Apple 风样式、资源路径（兼容 PyInstaller `_MEIPASS`） |
| `src/reminder_manager.py` | 浮窗生命周期：内存测试队列 + 业务队列，`ack → 落盘 → 关窗 → 下一条` |
| `assets/stand.svg`、`assets/drink.svg`、`assets/app.ico` | 图标资源 |
| `tests/test_ui.py`、`tests/test_popup.py`、`tests/test_reminder_queue.py`、`tests/test_custom_reminders.py` | UI/浮窗/队列/自定义提醒 |

### 3. 功能与取舍

- 浮窗关闭只有两条路：`ack_requested` 按钮（走 Scheduler 落盘后 `hide_after_ack`）与 `quit_cleanup()`（明确退出）；`closeEvent/keyPressEvent` 全部 ignore。
- 「新增任意提醒」：Scheduler 本来按 `self._config.tasks` 泛化，新增只加了 `add_task/remove_task` 入口；主窗改为按任务列表动态生成卡片与测试按钮，托盘菜单按签名重建，配置迁移无需改动。
- 取舍：新增/删除不做二次确认弹窗（避免模态阻塞与额外点击）；删除按钮只出现在自定义卡片，内置提醒只可关闭。
- 取舍：「柔和提示音」保留设置项但本期不出声（P1，PRD 默认关闭）。
- 取舍：保存间隔失败的错误文案直接来自 `models.validate_interval`（中文），UI 只负责展示，保证「一处校验」。

### 4. 真实命令与结果

```

python -m pytest                 → 130 passed（加入自定义提醒 15 用例 + CLI 3 用例后）
```

## 阶段三：托盘、单实例、开机自启

### 1. 目标

- 托盘常驻：打开设置 / 暂停恢复 / 每条提醒「测试X」/ 退出；tooltip 显示下次时间。
- 单实例：重复启动唤起原窗口，不产生第二套调度器。
- 开机自启（HKCU Run），首次启动不自动弹出提醒。
- 主窗关闭到托盘，`setQuitOnLastWindowClosed(False)`；退出是唯一允许关闭浮窗的路径。

### 2. 文件清单

| 文件 | 说明 |
| --- | --- |
| `src/tray_manager.py` | `QSystemTrayIcon` + 动态 `QMenu`；托盘不可用不崩溃 |
| `src/single_instance.py` | QLocalSocket 探测 → QLocalServer 监听；`activate_requested` |
| `src/startup.py` | HKCU `Software\Microsoft\Windows\CurrentVersion\Run`，源码态用 pythonw、冻结态用 exe |
| `app.py` | 装配、参数（`--config/--shift-minutes/--exit-after`）、每秒 QTimer、单实例接线 |
| `tests/test_system.py`、`tests/test_app_cli.py` | 真实 QLocalServer、隔离注册表键、菜单结构 |

### 3. 功能与取舍

- 实测 Windows 上同名 QLocalServer 两次 listen 都会成功，因此先 socket 探测再 listen（`removeServer` 兜底）。
- 自启只写 HKCU，不改 HKLM，不需要管理员权限。
- 取舍：托盘 `showMessage` 只用于「已最小化到托盘」一次性提示，健康提醒坚持用自绘浮窗（PRD 硬规则）。
- 取舍：单实例「探测→listen」非原子，极端并发下两个进程可能都进入启动；正常双击场景已验证（TC-026/027）。

### 4. 真实命令与结果

```
python -m pytest tests/test_system.py     → 10 passed
python -m pytest tests/test_app_cli.py    → 3 passed（修复 argparse 中 %APPDATA% 引起的 ValueError）
python app.py --config .e2e\custom\config.json --exit-after 30
  → 日志：单实例服务已启动 / 启动完成，版本 1.0.0 / 三条到期入队 / 逐条显示与确认 / 正常退出
```

### 5. 已知问题

- 真实托盘图标的点击与外观未人工截图验收（本机可创建托盘，见测试报告 §6）。
- Windows 安全桌面（UAC）与独占全屏无法保证浮窗可见（PRD 已声明边界）。

## 附：与 PRD 的偏差与假设汇总

| 项 | 实际 | 原因 |
| --- | --- | --- |
| Python 版本 | 3.14.7 | 本机仅有该版本；PySide6 6.11.2 支持 |
| 浮窗所在屏 | 鼠标所在屏（兜底主屏） | PRD 未指定多屏规则 |
| 新增任意提醒 | 已实现（超出 V1.0 两条固定任务） | 用户追加需求（「新增不同的提示也要能触发页面提醒」） |
| 提示音 | 设置项保留、不出声 | P1，PRD 默认关闭 |
| 测试提醒与真实提醒同时到期 | 真实提醒优先，测试提醒排后且不持久化 | 防止测试行为污染业务队列 |
| 删除自定义提醒 | 无二次确认，立即删除并 toast 提示 | 保持交互最短；如需确认可后续加 |
